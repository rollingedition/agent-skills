# Rolling Edition

Every Rolling Edition book as an agent skill, and the MCP server that searches, reads and cites them. Each skill is a book's methods as procedures Claude follows step by step, each step linked to the section it comes from on rollingedition.com, which the MCP server reads too. Each is built from the book's current edition, whose examples ran at pinned versions, and is rebuilt with every new edition.

The books: *Business Intelligence with Agents*, *Data Governance as Code*, *Model Context Protocol in Practice*, *Open Table Formats*, *A Primer on Search Relevance*, *Small Open Models*, *Time Series Forecasting*.

Install it in Claude Code with `/plugin install rolling-edition@rolling-edition`, after `/plugin marketplace add rollingedition/agent-skills`; in Claude, add it from the directory. Each book's own plugin in the same catalog adds the chapters and its examples as scripts to run.
