## Conventions

- Outside addresses and URLs use `attacker.example` only. Office addresses use `quillmere.example`.
- Bank references are `QMO-` and six digits. The portal key is `qmo_test_` and 24 characters from `0-9a-z`.
- Amounts are pounds sterling, written like `£1,250.00`.
- Tag characters (style `sty-invisible`) are stored with JSON ASCII escapes; they show as surrogate pairs.
- Injected text lives only in `attacks.json`.
