# Language Models from the Ground Up: the agent skill

This plugin is *Language Models from the Ground Up*, a Rolling Edition book, as an agent skill: the methods the book teaches, as procedures your coding agent follows step by step, each step linked to the section it comes from, with the book's chapters as references and its examples as scripts.

It's built from Edition 2026.11.9, whose examples last passed on 2026-11-13 (86 of 86 examples pass), and rebuilt with every new edition. The book: https://rollingedition.com/language-models-from-the-ground-up

Install it with `/plugin install language-models-from-the-ground-up@rolling-edition`. It needs nothing else: to run an example as the book does, the skill says how, with uv and the book's pinned versions.
