# Model Context Protocol in Practice: the agent skill

This plugin is *Model Context Protocol in Practice*, a Rolling Edition book, as an agent skill: the methods the book teaches, as procedures your coding agent follows step by step, each step linked to the section it comes from, with the book's chapters as references and its examples as scripts.

It's built from Edition 2026.11.10, whose examples last passed on 2026-11-10 (70 of 70 examples pass), and rebuilt with every new edition. The book: https://rollingedition.com/model-context-protocol-in-practice

Install it with `/plugin install model-context-protocol-in-practice@rolling-edition`. It needs nothing else: to run an example as the book does, the skill says how, with uv and the book's pinned versions.
