# Rolling Edition books

This plugin connects your agent to Rolling Edition's MCP server, so it can search every Rolling Edition book, read a section with its code examples and the versions they ran on, say what changed between editions, check a copy's edition code, fetch a book's agent skill, and cite the edition and section it used. The server is free and read-only, with no sign-in.

Install it with `/plugin install books@rolling-edition`, after `/plugin marketplace add rollingedition/agent-skills`. How to use it, and what each tool does: https://rollingedition.com/assistants
