# Business Intelligence with Agents: the agent skill

This plugin is *Business Intelligence with Agents*, a Rolling Edition book, as an agent skill: the methods the book teaches, as procedures your coding agent follows step by step, each step linked to the section it comes from, with the book's chapters as references and its examples as scripts.

It's built from Edition 2026.11.8, whose examples last passed on 2026-11-12 (78 of 78 examples pass), and rebuilt with every new edition. The book: https://rollingedition.com/business-intelligence-with-agents

Install it with `/plugin install business-intelligence-with-agents@rolling-edition`. It needs nothing else: to run an example as the book does, the skill says how, with uv and the book's pinned versions.
